## Representaion
Can be represented in 2 ways
- Adjacency Matrix
- Adjacency List

## Traversal Techniques
- Breadth First Search (BFS) - implemented using Queue data structure
- Depth First Search (DFS) - implemented using recursion 

## BFS-DFS Problems
- Number of provinces
- Rotten Oranges
- Flood fill algorithm

## Application of BFS-DFS
- Cycle Detection
